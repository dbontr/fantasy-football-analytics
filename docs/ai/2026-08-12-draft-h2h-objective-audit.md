# Draft H2H objective audit — 2026-08-12

## Boundary
This was run only after the Win Plan implementation and audit code were frozen at `3be3a71`. It uses already-consumed 2019-2025 Draft evidence and **cannot select, tune, or promote a policy**. The serving Draft policy remains unchanged.

The diagnostic asks a narrower question than the existing realized-starter-points benchmark: if each drafted roster receives retrospective optimal weekly lineup management, does the frozen SnapCount roster tend to convert its roster-quality edge into more 14-week head-to-head win credits? This is an evaluation ceiling, not a claim about actual historical managers or an independent holdout.

## Aggregate result
Across 336 paired rooms, SnapCount averaged 9.193 realized optimal-lineup H2H wins in 14 weeks.

- ESPN-market: 5.808 wins; SnapCount delta **+3.385**; paired win rate 78.6%.
- Value: 6.171 wins; delta **+3.022**; paired win rate 81.0%.
- Balanced: 8.554 wins; delta **+0.640**; paired win rate 53.3%.
- Zero-RB: 8.408 wins; delta **+0.786**; paired win rate 51.8%.
- Need-heavy: 9.098 wins; delta only **+0.095**; paired win rate 44.6%.
## Adverse evidence retained
The objective alignment is not uniform. Need-heavy is effectively tied in aggregate and beats SnapCount in paired-room frequency despite SnapCount's small positive mean. In 2023 SnapCount also trails ESPN-market (-0.156 wins), balanced (-0.552), and need-heavy (-0.510). Need-heavy is negative in 2021 (-0.063) and 2023 (-0.510).

Positive-season counts are 6/7 vs ESPN-market, 6/7 balanced, 7/7 value, 5/7 need-heavy, and 7/7 Zero-RB.

## Interpretation
The already-frozen policy's strong market/value roster advantage generally survives translation into a head-to-head objective under this retrospective optimal-lineup ceiling. It does **not** establish universal superiority over structural drafting, and it is not new policy-admission evidence. In particular, need-heavy remains the main unresolved competitor and must not be tuned against using these consumed seasons.

The correct next evidence remains prospective 2026: freeze the system first, record its decisions, then score actual game outcomes before changing behavior.
